# Матрица прав доступа

**Статус:** предлагаемая матрица для согласования. `DATA_MODEL.md` перечисляет четыре роли, но не закрепляет их права.

Обозначения:
- **Просмотр** — чтение информации в интерфейсе.
- **Нет** — действие запрещено предлагаемой матрицей.
- **После согласования** — модель не содержит достаточных данных или правил для безопасной реализации.

## Правила применения

1. Для `portfolio_owner` и `building_owner` предлагается режим только для чтения.
2. Для `hub_operator` любые управляющие операции пока не включены в подтверждённые права: сначала нужно согласовать операции и дополнить модель.
3. Для `platform_admin` административные операции также являются предложением, поскольку модель не описывает настройки платформы и управление пользователями.
4. Все права на объекты требуют связи `User` с `Portfolio` и/или `Site`; сейчас она не описана.
5. Если действие не реализовано, интерфейс не должен имитировать успешное изменение данных.
6. Для промышленной версии права должны проверяться не только в UI, но и на backend. В текущем MVP backend отсутствует, поэтому тестируется только интерфейсная логика.
